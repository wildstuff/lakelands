# The log format

*Stub.* The contract step (lakelands#2) writes this specification in
full, as its first complete draft; lakelands#14 is the review pass over
it.

The event log is the truth of a lake, and its format is published and
versioned so that a lake can be read without Lakelands. This document
will specify the events, their encoding, the hash chain that links them
and the provenance every event carries. A change to the format is a
change to this document first, with a version bump, and to the code
second.
